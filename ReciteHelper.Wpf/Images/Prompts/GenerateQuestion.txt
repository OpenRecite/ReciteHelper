Please generate review questions based on the text content.

Generate both short-answer questions and single-choice questions.

Short-answer questions:
- Use type = "ShortAnswer".
- Extract one key knowledge point per question.
- Replace the key knowledge point with ________ when the original sentence is suitable for memorization.
- For definition questions, format the stem as: 名词解释: 名词.
- Fill correct_answer with the expected answer text.
- Keep options and correct_option_ids as empty arrays.

Single-choice questions:
- Use type = "SingleChoice".
- Generate exactly four options with ids A, B, C, and D.
- Put only the stem in text. Do not embed A/B/C/D options inside text.
- Fill options as structured objects.
- Fill correct_option_ids with exactly one id, such as ["B"].
- Fill correct_answer with the same correct id, such as "B".
- Do not make all questions single-choice, and do not omit single-choice questions entirely.

If a sentence contains multiple knowledge points, generate multiple questions instead of multiple blanks in one question.
Divide the content into several chapters.

Return only valid JSON for List<Chapter>. Do not include Markdown fences.

The returned JSON shape is:

public class Chapter
{
    [JsonPropertyName("name")]
    [NOTNULL] public string Name { get; set; }
    [JsonPropertyName("number")]
    public int Number { get; set; }
    [JsonPropertyName("bank")]
    public List<Question>? Questions { get; set; }
    [JsonPropertyName("know")]
    public List<KnowledgePoint>? KnowledgePoints { get; set; }
}

public class Question
{
    // null means unanswered, true means correct, false means incorrect.
    [JsonPropertyName("status")]
    public bool? Status { get; set; }
    [JsonPropertyName("text")]
    public string? Text { get; set; }
    [JsonPropertyName("type")]
    public string Type { get; set; } // "ShortAnswer" or "SingleChoice"
    [JsonPropertyName("options")]
    public List<QuestionOption> Options { get; set; }
    [JsonPropertyName("correct_option_ids")]
    public List<string> CorrectOptionIds { get; set; }
    [JsonPropertyName("correct_answer")]
    public string? CorrectAnswer { get; set; }
    // Please keep this item as an empty list.
    [JsonPropertyName("review_tag")]
    public List<ReviewTag>? ReviewTag { get; set; }
}

public class QuestionOption
{
    [JsonPropertyName("id")]
    public string Id { get; set; } // "A", "B", "C", or "D"
    [JsonPropertyName("text")]
    public string Text { get; set; }
}

public class KnowledgePoint
{
    [JsonPropertyName("name")]
    public string? Name { get; set; }
    [JsonPropertyName("content")]
    public string? ContentMarkdown { get; set; }
    // Mark the knowledge point mastery status as false.
    public bool isMastered { get; set; }
}
